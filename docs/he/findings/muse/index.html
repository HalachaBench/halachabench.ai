מודלי Muse של Meta ניגשים למבחן

Muse Wonder Full קיבל 60.8, מעט אחרי Gemini 3.8 Flash. Muse Wonder קיבל 48.2, Muse Spark 1.3 קיבל 36.2, והקל שבהם, Muse Ember, קיבל 15.3.

ב-6 בנובמבר הוספנו שלושה ממודלי Muse של Meta, שהורצו דרך Muse Code CLI של Meta כשכלי הרשת, המעטפת וכתיבת הקבצים שלו כבויים, וכל הרצה נוטרה בזמן אמת. Muse Ember, מודל ה-Muse הקל ביותר של Meta, הצטרף ב-9 בנובמבר, ביום שבו שוחרר.

  • כל מדרגה כלפי מטה במשפחה עולה כ-12 נקודות. Muse Wonder Full גבוה ב-12.5 נקודות מ-Muse Wonder, ו-Muse Wonder גבוה ב-12.0 מ-Muse Spark 1.3; שני הפערים ברורים.
  • Muse Wonder Full ממוקם מעט אחרי Gemini 3.8 Flash (בלי הבדל ברור ביניהם) ובבירור אחרי Claude Opus 5.5.
  • ההרגלים של עוזר תכנות ניכרים. כ-25 מתוך 540 תשובות של Muse מעצבות את המובאות שלהן כקישורי Markdown לנתיבי קבצים או לכתובות אינטרנט פיקטיביים. המובאות עצמן רגילות, והתשובות נבדקו כפי שנכתבו.
